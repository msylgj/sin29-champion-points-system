# 积分与规则

本文描述系统使用的业务口径。快照冻结配置数值和组别映射，不冻结计算代码；如果未来修改算法，历史积分也可能重算。发布变更见[变更记录](../CHANGELOG.md)。

## 排名口径

- 排名候选人来自当年报名中积分弓种等于所选弓种的记录。
- 成绩按年度、赛季、姓名、距离及比赛弓种匹配；光弓、美猎弓和传统弓报名还可匹配同年度、赛季、姓名、距离下的无瞄弓成绩。
- 俱乐部取该选手当年满足所选积分弓种的最早报名记录，按赛季、创建时间及记录 ID 确定先后。成绩明细按春、夏、秋、冬季赛顺序展示，同季再按距离（由远至近）、弓种及赛制排列。

## 分项与汇总

1. 根据赛事年度、赛季选择适用的规则快照。快照包含基础积分、人数或队伍数系数、名次上限、组别映射及系数、兜底基础积分和默认人数。
2. 按赛制和排名取基础积分；未列出的名次或者超出人数系数段对应的排名上限时，使用兜底基础积分。
3. 用成绩的赛事、分组、弓种和距离查找赛事配置。排位赛与淘汰赛取个人人数，导入时缺省分组可由匹配的报名推断；团体及混双分别取团体和混双队伍数。导入时团体缺省为混合组，网页导入混双时使用混合组。未取得有效人数或队伍数为零时使用快照的默认人数；人数或队伍数为一时系数为 1，且不限制计分名次。
4. 根据成绩弓种和距离在快照中匹配组别；未匹配时组别系数为 0。团体与混双共用团体基础积分和队伍数系数表。
5. 完整计算「基础积分 × 人数或队伍数系数 × 组别系数」，再按四舍五入保留一位小数。年度和指定赛季汇总都累加已舍入的分项，不再对未舍入的分项求和。

## 规则版本与边界

- 后端首次引导时生成初始快照，适用于没有更晚版本的全部赛事。初始分值、系数由[计分实现](../backend/app/services/scoring_calculator.py)定义；组别映射在初始化时从字典读取。修改现行字典不会覆盖历史快照。
- 「创建新规则」复制最新版本的完整配置，可选任一不早于该版本起始赛季的已有赛事，将其赛季设为前版截止点（**包含该赛季**）。新规则从下一自然赛季起生效，冬季之后是下一年春季。比如前版截止到 2026 年秋季赛，新版从 2026 年冬季赛起适用，无论有关赛事在何时创建。
- 可编辑分值和系数范围为 0～10000，人数或队伍数区间须从 2 连续覆盖至无上限，每个弓种、距离组合只可映射一次。发布前应确认映射覆盖参赛项目：未匹配的项目为 0 分，空映射会使适用区间内所有项目计为 0 分。发布后配置只读；创建需以最新版本为基准。
- 只允许删除最新的非初始规则；删除后前版恢复持续生效。发布和删除都可能改变适用边界内已有赛事的计算结果，但不会删除报名或成绩。修正成绩、报名或人数这类事实同样会反映在后续计算中。

## Excel 导出

- 年度导出包含年度排名和成绩明细。
- 指定赛季导出按筛选后的参赛者重新计算该赛季的排名，沿用姓名及俱乐部筛选。标题包含当前年份、弓种和站次（春、夏、秋、冬对应第一、二、三、四站）。
- 指定赛季表按 50M、30M、18M、10M 和各赛制列展示对应分项的合计，无成绩留空，站次积分汇总所选赛事各分项；数值显示一位小数。文件基于[赛季 Excel 模板](../frontend/src/assets/season-export-template.xlsx)。
